 🍽️ Restaurant Billing System - Real Life POS
 A complete, real-life Restaurant Point of Sale (POS) system built in Python. Designed for actual use in restaurants, dhabas, cafes, and food stalls in Pakistan.
 
 🎯 What is this?
This is NOT a dummy college project. This is a **real-life billing system** that can be used from today in any restaurant. It handles:

20 Tables with Occupied/Available status
 **Complete Menu** Main Course, BBQ, Breads, Drinks, Desserts
**Auto Calculations** - Subtotal, 16% GST (Pakistan), Discount, Grand Total
**3 Payment Methods** - Cash, Card, JazzCash/Easypaisa
**Professional Receipt** - Like KFC/McDonald's thermal receipt
 **Daily Sales Report** - See total sale, orders, average bill
 **100% Offline** - No internet needed, SQLite database

 🚀 Who can use it?
 Small Restaurants & Dhabas
 Cafes & Fast Food
 Food Stalls & Home Chefs
